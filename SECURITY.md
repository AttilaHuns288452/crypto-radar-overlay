# Security Policy

## Supported Versions

This repository is a small local desktop app. The `main` branch is the supported version.

## Reporting a Vulnerability

Open a GitHub issue with a clear description and reproduction steps. Do not include private API keys, wallet keys, exchange credentials, or other secrets in issues.

## Data and Credentials

Crypto Radar Overlay uses public market-data endpoints and does not require exchange credentials. Do not add private exchange API keys to this app unless you first add secure local secret handling.
